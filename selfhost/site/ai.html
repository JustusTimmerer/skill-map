Make a map with an AI tool

An AI tool such as Claude can read your CV and make a Skill-Map for you. You get a map file, or a map that is already loaded in this browser.

How it works

  1. Give your CV to the AI tool.
  2. Paste the prompt below. The tool reads the description of the format on this site.
  3. The tool gives you a map file. On the start page, press “Open map file” and pick it. A tool that can use your browser can also load the map for you.
  4. Check the map and change it in the editor. The skills and the ratings are the guess of the tool from your CV, so correct what is wrong.

Prompt

Your CV goes only to the AI tool that you use. This site never sees it. The map stays in this browser, and “Export” saves a copy.
